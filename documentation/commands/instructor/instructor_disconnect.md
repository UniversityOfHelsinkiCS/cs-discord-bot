# /instructor_disconnect

Disconnects a user from the voice channel they are in.

- **Who:** Course instructors, faculty and admins
- **Where:** Any channel
- **Confirmation:** Yes

| Argument | Required | Description |
| --- | --- | --- |
| `user` | Yes | The user to disconnect, as an @mention. |

Instructors can disconnect users only from the voice channel of a course they instruct. Faculty and admins can disconnect anyone.
