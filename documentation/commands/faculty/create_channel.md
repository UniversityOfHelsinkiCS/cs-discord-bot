# /create_channel

Adds a text channel to the course. The course name is put in front, so `feedback` in the wepa course creates `wepa_feedback`.

- **Who:** Faculty and admins
- **Where:** A course channel
- **Confirmation:** No

| Argument | Required | Description |
| --- | --- | --- |
| `channel` | Yes | Name of the new channel. |

A course can have at most 10 added channels.
