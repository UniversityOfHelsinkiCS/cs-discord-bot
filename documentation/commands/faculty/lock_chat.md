# /lock_chat

Locks a course's channels so only its instructors, faculty and admins can post. Its category is shown with 🔐.

- **Who:** Faculty and admins
- **Where:** Any channel
- **Confirmation:** Yes

| Argument | Required | Description |
| --- | --- | --- |
| `course` | Yes | The course to lock. Autocompletes with the courses that are not locked. |

Has the [course cooldown](../../commands.md#course-cooldown).
