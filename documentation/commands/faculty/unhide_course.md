# /unhide_course

Makes a private course public again. Its category is shown with 📚.

- **Who:** Faculty and admins
- **Where:** Any channel
- **Confirmation:** Yes

| Argument | Required | Description |
| --- | --- | --- |
| `course` | Yes | The course to make public. Autocompletes with the private courses. |

Has the [course cooldown](../../commands.md#course-cooldown).
