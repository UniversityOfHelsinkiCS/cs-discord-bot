# /hide_course

Makes a course private: it is removed from `#guide`, `/courses` and `/join`, and students can join it only with the course link. Its category is shown with 👻.

- **Who:** Faculty and admins
- **Where:** Any channel
- **Confirmation:** Yes

| Argument | Required | Description |
| --- | --- | --- |
| `course` | Yes | The course to hide. Autocompletes with the public courses. |

Has the [course cooldown](../../commands.md#course-cooldown).
