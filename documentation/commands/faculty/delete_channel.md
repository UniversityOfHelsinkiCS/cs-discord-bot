# /delete_channel

Deletes a channel that was added to the course. The default announcement, general and voice channels can't be deleted.

- **Who:** Faculty and admins
- **Where:** A course channel
- **Confirmation:** Yes

| Argument | Required | Description |
| --- | --- | --- |
| `channel` | Yes | The channel to delete. Autocompletes with the channels added to this course. |
