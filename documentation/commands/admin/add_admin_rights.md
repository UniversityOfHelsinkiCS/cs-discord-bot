## /add_admin_rights

- :heavy_check_mark: Slash command, replies ephemerally (only visible to the invoker).
- :heavy_check_mark: Requires confirmation.
- :heavy_check_mark: Needs argument: `user` — the user to be made admin.
- :x: Only usable by members with Discord's Administrator permission. The admin flag in the database is not checked, so this command can be used to grant the first admin.
